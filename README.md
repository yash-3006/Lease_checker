# Lease Risk Checker (Gemini)

Deploy on Vercel:
1. Push this folder to a GitHub repo (or run `npx vercel` inside it).
2. In Vercel, import the repo. Framework preset: Other.
3. Add environment variable GEMINI_API_KEY (get one at https://aistudio.google.com/apikey).
4. Deploy. Your link will be https://<project>.vercel.app

Optional: set GEMINI_MODEL (default gemini-2.5-flash).
